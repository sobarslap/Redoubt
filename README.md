# AegisMem

> A framework-free (no LangChain / LlamaIndex), production-grade **agent runtime**
> in pure Python. Memory, retrieval, context, tools, security, observability, and
> evaluation are each independent, benchmarked subsystems behind a deterministic
> execution contract.

Production agents break on four failure modes: **hallucination, latency,
prompt-injection/poisoning, and runaway token cost.** AegisMem addresses each with
mechanisms that are *measurable, deterministic where possible, failure-aware,
secure, testable, and reproducible* — proven by a benchmark suite and a red-team
suite, not asserted.

## Architecture

```
Request
  → Validation        (typed Pydantic contract, size limits)
  → Guardrails        (trust labels, injection scan, PII) ......... src/aegismem/guardrails
  → Budget allocation (retrieval + context + tool budgets)
  → Retrieval         (JIT hybrid BM25+vector+rerank, threshold) .. src/aegismem/retrieval
  → Execution         (provider-agnostic LLM ↔ guarded tools) ..... src/aegismem/execution
  → Output validation (grounding/citation, leakage filter)
  → Response          (citations, usage, timings, trace_id)

  memory (lifecycle + conflict + provenance) ..................... src/aegismem/memory
  context (budget allocator, watchdog, verified compaction) ...... src/aegismem/context
  mcp (progressive discovery; discovery ≠ authorization) ......... src/aegismem/mcp
  observability (trace store + deterministic replay) ............. src/aegismem/observability
```

SQLite (WAL) is the source of truth; the vector and BM25 indexes are derived,
rebuildable accelerators. The `MemoryStore` / `LLMClient` / `TraceSink` interfaces
are the documented production swap points (pgvector·Qdrant / Gemini·Claude·Ollama).

## Quickstart

```bash
uv sync --group dev
uv run aegismem version
uv run pytest                       # unit + integration + adversarial + e2e
uv run python -m evals.run          # 107-scenario golden dataset (the CI eval gate)
uv run python -m benchmarks.run --scales 10,1000,100000,1000000
```

### Run the DevOps/SRE demo (keyless, offline)

```bash
uv run python -m demo.devops_sre.run
```

One scripted incident exercises every subsystem: recall infra facts → the
conflict resolver **supersedes** a stale `MySQL→Postgres` fact → the guarded
`Execute_Tool` gateway pulls metrics/logs → a **poisoned log line is treated as
data and the injected restart is refused** → verified compaction preserves
`db=postgres` → a remediation with **citations**. The run is replayable:

```bash
uv run aegismem replay <run_id> --trace-path traces/demo.jsonl
```

Swap the offline `MockProvider` for Gemini / Claude / Ollama by constructing the
runtime with a real provider — the contract is identical (`uv sync --group llm`).

## Guarantees & invariants

- **Memory corruption = 0** — injected untrusted writes are quarantined, never active truth.
- **Unauthorized tool execution = 0** — authorization lives in the gateway, never the model.
- **Attack-success-rate → 0** — a structural trust boundary (fenced untrusted data) backed by a fail-closed detector.
- **Empty memory over vague memory** — retrieval returns nothing rather than a weakly-related fact.
- **Verified compaction** — a lossy or contradictory summary is rejected, previous context preserved.
- **Deterministic replay** — any run reconstructs from `run_id`.
